    Это официальная интеграция с Яндексом?
    Нет. Локус — независимый сервис, не продукт и не представительство Яндекса. Публичного Business API у Яндекс.Карт нет. Клиент добавляет корпоративную почту Локуса Farot11@ya.ru представителем. Этот аккаунт ведёт тексты карточки. Пароль Яндекса не просим. «Яндекс.Карты» и «Яндекс.Бизнес» — товарные знаки правообладателя.
    Вы публикуете без моего согласия?
    По умолчанию сервис сам генерирует текст, читает его и отправляет в Яндекс аккаунтом представителя. Кнопка «Нужно согласование» — добровольный режим: если она включена, новости и ответы сначала приходят в бот, в Яндекс уходят после кнопки там. Публичного API карточки у Яндекса нет.
    Что с персональными данными?
    Основные данные — в России, обработка по 152-ФЗ и поручению оператора. Перед отправкой во внешний сервис текст отзыва обезличиваем: контакты, ссылки и ники заменяем метками, имя автора не передаём. Внешние сервисы получают только обезличенный текст и только если это допустимо договором; чувствительные данные остаются в российском контуре. Подробнее — в политике.
    Подходит ли для сети и франшизы?
    Да. У каждой точки — свой набор квот и отчёт. В кабинете есть роли и оформление: цвета и тон текстов. Для 25+ точек условия обсуждаем отдельно.
